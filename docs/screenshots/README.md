Drop your screenshots in here with these exact names and they'll show up
automatically in the main README:

- `screenshot1.png` — e.g. the menu bar icon + dropdown menu
- `screenshot2.png` — e.g. the Settings… window

Any image format works, but PNG is recommended. Recommended size: crop tight
around the menu bar area rather than a full-screen capture, so it stays
readable when GitHub shrinks it in the README.
